The whole flow, end to end — no SQL strings in application code:

```go
package main

import (
    "context"
    "log"

    "github.com/khoale-2804/pgb/core"
    "github.com/jackc/pgx/v5/pgxpool"
    db "github.com/khoale-2804/shop/db"
)

func main() {
    ctx := context.Background()
    pool, err := pgxpool.New(ctx, "postgres://localhost/shop")
    if err != nil {
        log.Fatal(err)
    }

    // static layer: insert, read, update — no hand-written SQL
    u, err := db.InsertUser(ctx, pool, db.InsertUserParams{
        Email: "ada@example.com",
        Name:  "Ada",
    })

    // search layer: BM25 with fuzzy matching, scored, snippeted
    hits, err := db.SearchProducts(ctx, pool, "runing shoes", db.SearchOpts{
        Fuzzy:   1,
        Snippet: "description",
    })
    for _, h := range hits {
        log.Printf("%.2f  %s", h.Score, h.Row.Title)
    }
}
```

Two editions, one compiler: the **sqlc plugin edition** (v0.1) drops into
your existing sqlc workflow; the **standalone ORM edition** (v0.2+) brings
the full toolkit on the Go module proxy.
